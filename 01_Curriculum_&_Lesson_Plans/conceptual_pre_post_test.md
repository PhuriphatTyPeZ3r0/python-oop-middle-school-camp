## 📋 ชุดข้อสอบ 10 ข้อ (Student Test Sheet)

#### 1. ในการเขียนโปรแกรม ตัวแปร (Variable) มีหน้าที่เปรียบเสมือนสิ่งใดในชีวิตจริง?
- ก. ป้ายบอกทางแยกในสวนสาธารณะ
- ข. กล่องหรือหีบสมบัติที่มีป้ายชื่อ สำหรับเก็บสิ่งของไว้ด้านใน
- ค. เครื่องถ่ายเอกสารที่ปั๊มเอกสารออกมาจำนวนมาก
- ง. ปลั๊กไฟที่ใช้เชื่อมต่ออินเทอร์เน็ต

#### 2. พิจารณาโค้ดต่อไปนี้:
```python
player_hp = 25
if player_hp <= 0:
    print("ตายแล้ว")
elif player_hp < 30:
    print("อันตราย!")
else:
    print("ปลอดภัย")
```
**ผลลัพธ์ที่ปรากฏบนหน้าจอคือข้อใด?**
- ก. ตายแล้ว
- ข. อันตราย!
- ค. ปลอดภัย
- ง. เกิด Error ไม่แสดงผลลัพธ์

#### 3. ข้อใดอธิบายการทำงานของ While Loop ได้ถูกต้องที่สุด?
- ก. คำสั่งที่ทำงานเพียงครั้งเดียวแล้วจบการทำงานทันที
- ข. คำสั่งที่สุ่มเลือกเส้นทางเดินของโปรแกรม
- ค. คำสั่งที่ทำงานซ้ำไปเรื่อยๆ ตราบใดที่เงื่อนไขยังคงเป็นจริง (True)
- ง. คำสั่งที่ใช้สำหรับตั้งชื่อตัวละครในเกม

#### 4. ข้อใดคือประโยชน์หลักของการสร้าง "ฟังก์ชัน (Function)" ด้วยคำสั่ง `def`?
- ก. ทำให้คอมพิวเตอร์ทำงานเร็วขึ้น 10 เท่า
- ข. รวมชุดคำสั่งที่ต้องใช้บ่อยๆ ไว้เป็นชื่อเดียว เรียกใช้ซ้ำได้โดยไม่ต้องพิมพ์ใหม่
- ค. ใช้สำหรับลบตัวแปรที่ไม่ได้ใช้ออกจากหน่วยความจำ
- ง. เปลี่ยนสีตัวอักษรบนหน้าจอให้สวยงาม

#### 5. ถ้าเปรียบเทียบกับ "การทำขนมคุกกี้" ข้อใดเปรียบได้กับ **Class** และ **Object** ตามลำดับ?
- ก. ตัวขนมคุกกี้ และ เตาอบขนม
- ข. แป้งทำขนม และ กลิ่นวานิลลา
- ค. แม่พิมพ์ขนมคุกกี้ และ ตัวขนมคุกกี้ที่ปั๊มออกมาจริง
- ง. จานใส่ขนม และ กล่องใส่ขนม

#### 6. ในโค้ด `hero1 = Hero("Arthur", 100)` สิ่งใดคือ **Object** ที่ถูกสร้างขึ้นในหน่วยความจำ?
- ก. `Hero`
- ข. `hero1`
- ค. `"Arthur"`
- ง. `100`

#### 7. ข้อมูลประจำตัวของตัวละคร เช่น `name`, `hp`, `attack_power` ในทาง OOP เราเรียกว่าอะไร?
- ก. Methods (เมธอด)
- ข. Loops (ลูป)
- ค. Attributes (คุณลักษณะ/แอตทริบิวต์)
- ง. Conditionals (เงื่อนไข)

#### 8. การกระทำหรือท่าไม้ตายของตัวละคร เช่น `attack()` หรือ `heal()` ในทาง OOP เราเรียกว่าอะไร?
- ก. Methods (เมธอด)
- ข. Attributes (แอตทริบิวต์)
- ค. Data Types (ชนิดข้อมูล)
- ง. Variables (ตัวแปร)

#### 9. ทำไมในเมธอดของคลาสภาษา Python จึงต้องมีคำว่า `self` อยู่ในวงเล็บเสมอ?
- ก. เพื่อบอกให้โปรแกรมรู้ว่านี่คือคาถาเวทมนตร์
- ข. เป็นคำชี้ระบุว่า การกระทำหรือข้อมูลนี้เป็น **"ของตัวออบเจกต์นั้นเอง"** ไม่ใช่ของตัวอื่น
- ค. เป็นคำบังคับสำหรับสั่งให้พิมพ์ข้อความออกทางหน้าจอ
- ง. เพื่อทำให้ตัวละครเดินหน้าไปข้างหน้า 1 ก้าว

#### 10. ถ้าเราสร้างคลาส `Hero` ขึ้นมา 1 คลาส เราจะสามารถนำไปสร้างออบเจกต์ฮีโร่ได้กี่ตัว?
- ก. สร้างได้เพียงตัวเดียวเท่านั้น
- ข. สร้างได้ไม่เกิน 2 ตัว (ผู้เล่น 1 และ ผู้เล่น 2)
- ค. สร้างได้ไม่จำกัดจำนวน ขึ้นอยู่กับความต้องการในโปรแกรม
- ง. ต้องสร้างคลาสใหม่ทุกครั้งที่ต้องการตัวละครใหม่

### 📊 เกณฑ์การประเมินพัฒนาการ (Normalized Gain Score):
$$\text{Learning Gain} = \frac{\text{Post-test} - \text{Pre-test}}{10 - \text{Pre-test}}$$
- **High Gain ($> 0.7$):** เกิดการปรับเปลี่ยน Schema เชิงมโนทัศน์ได้อย่างสมบูรณ์แบบ

- **Low Gain ($< 0.3$):** ยังสับสนระหว่าง Procedural กับ OOP แนะนำให้ทบทวนด้วยบัตรคำ Parsons Problems
