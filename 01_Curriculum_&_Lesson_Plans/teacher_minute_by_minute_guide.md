**หลักสูตร:** Young Python & OOP Coding Camp (12 ชั่วโมง / 2 วัน)  
**กลุ่มเป้าหมาย:** นักเรียนระดับมัธยมศึกษาตอนต้น (ม.1 - ม.3)  
**ห้องปฏิบัติการ:** ห้องคอมพิวเตอร์แบบ 1 คนต่อ 1 เครื่อง พร้อมโปรเจกเตอร์

## 📅 วันที่ 1: ปูพื้นฐานสู่เส้นทางโค้ดเดอร์ (Python Fundamentals)

### ⏰ ชั่วโมงที่ 1 (09:00 - 10:00): ปฐมนิเทศกิลด์และแท่นตีดาบ Thonny IDE
- **Say (สิ่งที่ครูต้องพูด):** *"ยินดีต้อนรับสู่กิลด์นักผจญภัย วันนี้เราจะเรียนรู้วิธีสั่งการคอมพิวเตอร์ด้วยภาษา Python เพื่อสร้างตัวละครในเกมของเราเอง"*
- **Do (สิ่งที่ครูต้องทำ):**
  1. ให้นักเรียนเปิดโปรแกรม **Thonny IDE**
  2. สั่งให้นักเรียนคลิกเมนู `View` $\rightarrow$ ติ๊กเลือก `Variables` และ `Shell`
  3. สอนพิมพ์คำสั่งแรก `print("ยินดีต้อนรับสู่โลก Python")`
- **CFU (คำถามเช็คความเข้าใจ):** *"ถ้าครูลืมใส่เครื่องหมายคำพูดรอบข้อความ จะเกิด Error อะไรขึ้นใน Shell?"* (คำตอบ: `SyntaxError` หรือ `NameError`)

### ⏰ ชั่วโมงที่ 2 (10:00 - 11:30): Module 1: ตัวแปร (Variables) และชนิดข้อมูล
- **Say:** *"ตัวแปรก็เหมือนกล่องเก็บไอเทม ถ้าเราตั้งชื่อกล่องว่า `player_hp` เราก็สามารถใส่ตัวเลข 100 ลงไปได้"*
- **Do:**
  - ให้นักเรียนพิมพ์ตัวแปร 4 ชนิด: `String` (ชื่อ), `Int` (เลือด), `Float` (ความเร็ว), `Bool` (สถานะรอดชีวิต)
  - ให้นักเรียนดูในหน้าต่าง `Variables` ทางขวามือใน Thonny ว่ามีกล่องตัวแปรปรากฏขึ้นมาจริง
- **CFU:** *"ถ้าค่า `is_alive = True` แล้วตัวละครโดนโจมตีจนเลือดหมด ค่านี้ควรเปลี่ยนเป็นอะไร?"* (คำตอบ: `False`)

### ⏰ ชั่วโมงที่ 3 (11:30 - 12:30): Module 2: เงื่อนไขและทางแยก (Conditionals)
- **Say:** *"เกมจะสนุกต้องมีทางแยก ถ้าเลือดเหลือต่ำกว่า 30 ให้เปิดไฟเตือนภัยสีแดง"*
- **Do:**
  - สาธิตโครงสร้าง `if`, `elif`, `else`
  - ทำเน้นย้ำเรื่องเครื่องหมายโคลอน (`:`) ท้ายประโยค และการเคาะย่อหน้า (Indentation)
- **CFU:** *"ทำไมบรรทัดใต้ `if` ต้องเคาะย่อหน้าเข้าไป?"* (คำตอบ: เพื่อบอกคอมพิวเตอร์ว่าคำสั่งนี้เป็นลูกน้องของเงื่อนไขนั้น)

--- *(พักรับประทานอาหารกลางวัน 12:30 - 13:30)* ---

### ⏰ ชั่วโมงที่ 4 (13:30 - 15:00): Module 3: ลูปฟาร์มเลเวล (Loops)
- **Say:** *"การฟาร์มมอนสเตอร์คือการตีซ้ำๆ เราจะไม่เขียนคำสั่งฟันดาบ 10 บรรทัด แต่เราจะใช้ While Loop"*
- **Do:**
  - ให้นักเรียนเขียน While Loop ลดค่า Stamina จาก 3 ลงเหลือ 0
  - แกล้งสาธิตการลืมเขียนบรรทัด `stamina = stamina - 1` เพื่อให้นักเรียนเห็นปรากฏการณ์ **Infinite Loop** บนหน้าจอ แล้วสอนวิธีกดปุ่ม Stop สีแดงใน Thonny
- **CFU:** *"ถ้าเงื่อนไขใน while เป็นจริงตลอดเวลา จะเกิดอะไรขึ้นกับโปรแกรม?"* (คำตอบ: โปรแกรมจะรันวนไม่หยุดจนค้าง)

### ⏰ ชั่วโมงที่ 5-6 (15:00 - 16:30): Module 4: ฟังก์ชันคัมภีร์เวทมนตร์ (Functions)
- **Say:** *"ฟังก์ชันคือการบันทึกสูตรเวทมนตร์ไว้ในคัมภีร์ เมื่อต้องการใช้ แค่เรียกชื่อฟังก์ชันนั้นขึ้นมา"*
- **Do:**
  - เขียนฟังก์ชัน `def cast_fireball(target, power):`
  - ให้นักเรียนทดลองส่งชื่อเพื่อนข้างโต๊ะเข้าไปเป็นพารามิเตอร์ `target`
  - แจกการ์ดสะสม EXP สำหรับนักเรียนที่ทำแบบฝึกหัดเสร็จ

## 📅 วันที่ 2: มหาเวทแห่งวัตถุและลานประลอง (OOP & Tournament)

### ⏰ ชั่วโมงที่ 7 (09:00 - 10:00): Module 5: Consumer Stage (ใช้ออบเจกต์รอบตัว)
- **Say:** *"ความจริงแล้วพวกเราใช้ออบเจกต์มาตั้งแต่วันแรก เครื่องหมายจุด (.) คือกุญแจไขความสามารถ"*
- **Do:**
  - แสดงการใช้ `hero_name.upper()` และโมดูล `turtle`
  - ชี้ให้นักเรียนเห็นว่าสิ่งที่มีข้อมูลและการกระทำในตัว เรียกว่า **Object**
- **CFU:** *"ในคำสั่ง `turtle.forward(100)` อะไรคือออบเจกต์ และอะไรคือเมธอด?"* (คำตอบ: `turtle` คือออบเจกต์, `forward` คือเมธอด)

### ⏰ ชั่วโมงที่ 8 (10:00 - 11:30): Module 6: Producer Stage (แม่พิมพ์ Class & `__init__`)
- **Say:** *"Class คือแม่พิมพ์ขนมคุกกี้ ส่วน Object คือตัวขนมที่ปั๊มออกมาจริง"*
- **Do:**
  - เขียนคลาส `Hero` บนกระดาน อธิบายคำว่า `__init__`
  - เปิดหน้าต่าง `Object inspector` ใน Thonny แสดงให้เห็น Memory ID ของออบเจกต์
- **CFU:** *"แม่พิมพ์กับตัวขนม สิ่งไหนกินได้จริง? และระหว่าง Class กับ Object สิ่งไหนคือตัวที่อยู่ในหน่วยความจำจริง?"* (คำตอบ: ตัวขนม และ Object)

### ⏰ ชั่วโมงที่ 9 (11:30 - 12:30): Module 7-8: ไขความลับของ `self` และ Methods
- **Say:** *"self คือสรรพนาม 'ของฉันเอง' เพื่อบอกว่าลดเลือดของตัวฉัน ไม่ใช่เลือดของเพื่อน"*
- **Do:**
  - สร้างเมธอด `attack(self, enemy)` และ `take_damage(self, damage)`
  - ให้นักเรียนดูว่าเมื่อ `player1.attack(player2)` ค่าเลือดในหน้าต่าง `Variables` ของ `player2` ลดลงจริง
- **CFU:** *"ถ้าในเมธอดลืมเขียนคำว่า `self` ในวงเล็บ จะเกิด Error อะไรขึ้น?"* (คำตอบ: `TypeError` หรือ `NameError`)
